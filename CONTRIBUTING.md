# Contribuir / Contribuir / Contribute

Puedes abrir una pregunta o proponer una mejora en catalán, español o inglés. No hace falta saber programar para explicar dónde te has atascado.

1. Describe qué querías hacer, qué ocurrió y qué esperabas.
2. Usa un ejemplo ficticio. No publiques clientes, conversaciones privadas, credenciales ni facturas.
3. Para un cambio de código, conserva una prueba del fallo, haz el cambio mínimo y ejecuta `npm test` y `npm run build`.
4. Para traducciones, indica idioma, contexto y motivo. No marques una revisión de IA como aceptación de un hablante competente.
5. Para otra categoría de negocio, explica la tarea del visitante y qué sección o dato necesita cambiar. No basta con recolorear el ejemplo.

La biblioteca crece con problemas observados. Una nueva dependencia necesita un beneficio concreto y una persona que pueda mantenerla. Una contribución no tiene plazo de respuesta garantizado.

Original contributions are submitted under this repository's MIT license. Do not contribute third-party photos, proprietary platform skills or copied websites without the relevant rights.
