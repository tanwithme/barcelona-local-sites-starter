## ¿Cómo uso un prompt? / Com faig servir un prompt? / How do I use a prompt?

**ES:** Abre el archivo y copia solo el bloque de texto en tu asistente. Puedes usarlo tal cual: si falta contexto, te pedirá lo imprescindible. En ChatGPT, adjunta el brief y los archivos pertinentes si necesitas que los lea. Subir `AGENTS.md` o un `SKILL.md` aporta instrucciones como contexto; no instala agentes ni conexiones. Para editar el repositorio, usa un asistente con acceso a esa carpeta.

**CA:** Obre el fitxer i copia només el bloc de text a l'assistent. El pots fer servir tal com està: si falta context, et demanarà el que sigui imprescindible. A ChatGPT, adjunta el brífing i els fitxers pertinents si necessites que els llegeixi. Pujar `AGENTS.md` o un `SKILL.md` aporta instruccions com a context; no instal·la agents ni connexions. Per editar el repositori, fes servir un assistent amb accés a la carpeta.

**EN:** Open the file and copy only its text block into your assistant. It works as written: if context is missing, the assistant should ask only for what matters. In ChatGPT, attach the brief and relevant files when you need it to read them. Uploading `AGENTS.md` or `SKILL.md` supplies context; it does not install agents or connections. To edit this repository, use an assistant that can access the folder.

## Things that are easy to confuse

| Term | Plain meaning |
| --- | --- |
| Brief | The agreed facts, customer task and scope of the website. |
| Repository | The project folder plus its recorded change history. |
| Commit | A saved point in that history that helps you compare and recover changes. |
| Build | Turn the source files into the website files that a browser can display. |
| Preview | A version you can inspect before treating it as the public customer site. |
| Domain | The website's address. Buying it is a separate decision from making the design. |
| Hosting | The service that makes the website available online. Check ownership and recurring cost. |
| Figma | A design workspace. A design or clickable prototype does not by itself prove a deployed website exists. |
| Provenance | A disclosed statement about where the site came from, such as the optional lowercase `tanwithme` marker. |

Ask the coach to explain any of these in your chosen language with an example from your project.

## Useful boundaries

**ChatGPT Sites in Barcelona:** the [official FAQ](https://help.openai.com/en/articles/20001339-creating-and-managing-chatgpt-sites), checked 7 September 2026, excludes the EEA, Switzerland and UK at launch and excludes Free/Go. A plan upgrade alone does not solve regional availability. Use the local static starter now, with Figma if useful. The Sites prompt is conditional; it is not a claim that Sites is enabled in Spain.

**WhatsApp:** a button can open an enquiry without adding a form/database to your website. It does not erase data handling at the hosting service or WhatsApp. Say “ask for an appointment” unless the business actually confirms bookings automatically.

**Instagram images:** public visibility is not permission. Ask the owner for the original file and permission to use it. A feed is optional and adds a dependency; a small set of approved photos is easier to maintain.

**Three languages:** an AI can draft and compare copy. A competent/native reviewer and the owner must still review language and facts before a real release. Keep the business name and actual address accurate across all versions.

**The `tanwithme` marker:** it is optional public attribution, disclosed to and approved by the business owner. It is not a tracking system. No marker can guarantee that a search engine will find every site. A mark only in the prompt or a private backend file cannot be found by a public search. A visible public match is a candidate for verification, not permission for automated outreach.

**When something breaks:** copy the error, say what you expected, and describe the last change. Remove passwords, tokens, private customer messages and other personal information. The assistant should preserve the working version, investigate one likely cause and tell you what it actually tested.
