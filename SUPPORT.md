# Ayuda / Ajuda / Help

Empieza por [START-HERE.md](START-HERE.md) o [Ayuda](docs/help.md). Pregunta a tu asistente en español, català o English; no tienes que traducir un error para pedir ayuda.

Para una duda del pack, abre una **Question / Pregunta** en Issues si el repositorio lo permite. Describe tu objetivo y copia solo el error necesario. Sustituye nombres, teléfonos y dominios de clientes por ejemplos ficticios. No publiques contraseñas ni conversaciones. La comunidad puede ayudar; no hay un tiempo de respuesta prometido.
